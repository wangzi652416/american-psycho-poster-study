# 美国精神病人 · 海报研究

六章交互演示：名片入场、电影与身份、八张海报、设计分析、马格利特对照、结束页。

`index.html` 是可独立运行的静态页面，保留真实 DOM、字体、图片和 JavaScript 交互，全部运行资源已内嵌。可放在 GitHub Pages 仓库根目录；无需构建工具或服务器端程序，也支持仓库子路径。

上下方向键或页面上下按钮切换章节；海报展厅的左右方向键切换海报。作品原始来源可从页面菜单中的“作品与资料”查看。完整资料说明见 [SOURCES.md](SOURCES.md)，字体和代码许可见 [THIRD-PARTY-NOTICES.txt](THIRD-PARTY-NOTICES.txt)。
